# CODE / CHAOS — Linha Zero

[Baixar Linha Zero para Windows](https://github.com/Murillou4/linha-zero-downloads/releases/latest/download/Linha.Zero.Windows.zip)

1. Extraia todos os arquivos do ZIP para uma pasta sua.
2. Abra **Jogar Linha Zero.exe**.
3. Use o mesmo executável sempre que for jogar. O launcher consulta o canal estável, baixa os blocos alterados e abre o jogo quando a atualização termina.

Este repositório reúne os arquivos de distribuição e os manifestos de atualização do jogo.
